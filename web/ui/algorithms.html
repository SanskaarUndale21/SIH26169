Algorithms

Swap in your own detector, tracker or pointing controller and test it on the same virtual camera, disturbances and spec metrics as the built-in ones. Each algorithm is one Python class.

How your code plugs in

Every frame runs these three stages in order. Replace any one; the others, the search pattern, lock logic and all scoring stay the same, so comparisons are fair.

Detector

detect(image) → [Detection(x, y, score)]

Gets the raw 8-bit camera frame. Returns every spot that might be the beacon.

Tracker

update(dt, measurement) → (x, y) | None

Gets the detection nearest its last estimate, or None when missed. Returns where the beacon is now.

Controller

compute(err_x°, err_y°, dt) → (pan°/s, tilt°/s)

Gets the estimate's offset from the image centre. Returns gimbal rates, clamped to the speed limits.
